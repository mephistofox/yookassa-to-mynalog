# Встраивание в fxTunnel

Пакет `github.com/mephistofox/yookassa-to-mynalog/pkg/receipts` — публичная
Go-библиотека. Он не запускает HTTP-сервер, процесс или контейнер и не импортирует
SQLite. Приложение создаёт `Engine` со своим `state.Store` и `Sender`, затем
запускает `receipts.NewWorker(engine).Run(ctx)` как goroutine.

`Worker.Wake()` безопасен для обработчика успешной оплаты и ничего не отправляет
в ФНС синхронно. Периодический GET-сканер ЮKassa сохраняется как восстановление
пропущенных webhook и оплат после рестарта. `Worker.Do(ctx, action)` последовательно
выполняет административные операции между циклами очереди.

Интерфейс `pkg/state.Store` позволяет хранить очередь в PostgreSQL fxTunnel.
`Save` обязан одной транзакцией сохранять весь набор записей (доход + outbox),
а потеря межпроцессной блокировки должна приводить к ошибке дальнейших записей.
Переоткрывать соединение под старым worker после потери блокировки нельзя.
Ротируемый токен `auth.refresh` должен шифроваться адаптером хранения.

`List` возвращает только незавершённые записи (без `done`, `sent`, `superseded`),
чтобы история не загружалась в память при каждом тике. Завершённые записи
сохраняются и доступны через `Get`, обеспечивая дедупликацию.

`Sender` адаптирует существующий SMTP-сервис fxTunnel. Он должен возвращать
ошибку при выключенной почте, соблюдать deadline контекста и использовать
стабильный Message-ID. Успешное подтверждение DATA считается доставкой,
независимо от результата QUIT. Секреты получает родительское приложение.

`pkg/sqlitestate` и `cmd/receipts` сохранены как необязательный standalone-адаптер;
для встроенного режима они не нужны. `LoadConfig` читает окружение для CLI;
приложение передаёт заполненный `receipts.Config` напрямую.
